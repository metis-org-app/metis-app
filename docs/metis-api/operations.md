# metis-api operations

The API contract the UI must build against. Every UI feature is checked against this list before it is
built: only the operations that exist here can be wired to the backend; anything else is UI-only or
future work and must be labeled as such.

- **Source of truth:** `docs/metis-api/openapi.json` (OpenAPI 3.1.1, generated by metis-api).
- **Live URL:** `https://metis-api-production-c275.up.railway.app/openapi/v1.json`
- **Refresh** (when the backend team says the API changed):

  ```sh
  curl -s https://metis-api-production-c275.up.railway.app/openapi/v1.json -o docs/metis-api/openapi.json
  ```

  then regenerate the list below from the new spec and note what changed. Never paste the URL in a
  chat again — this file is the reference.

- **How to use:** match the feature against the operations below; if it needs something that is not
  here (e.g. per-question AI regeneration, stored source materials), build the UI without it or as a
  visible "future" state and tell the owner — do not invent endpoints.

## Capability notes for the assessment-creation flow

Checked on 2026-11-02 against the spec above.

| Capability                                             | Operation                                                                                                             | Status                                                               |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Draft an assessment from a prompt + uploaded materials | `POST /api/assessments/generate` (multipart: topic, level, difficulty, allowedTypes, instructions, sourceText, files) | available                                                            |
| Save a draft in one call (AI draft)                    | `POST /api/assessments` with items                                                                                    | available                                                            |
| Reorder questions                                      | `PUT /api/assessments/{id}/items/order`                                                                               | available                                                            |
| Remove a question                                      | `DELETE /api/assessments/{id}/items/{itemId}`                                                                         | available                                                            |
| Add one question at the end                            | `POST /api/assessments/{id}/items`                                                                                    | available                                                            |
| Edit a question (type can change)                      | `PUT /api/assessments/{id}/items/{itemId}`                                                                            | available                                                            |
| Per-question AI regeneration                           | —                                                                                                                     | not in the API                                                       |
| Storing source materials with the assessment           | —                                                                                                                     | not in the API                                                       |
| Streaming question-by-question generation              | —                                                                                                                     | not in the API (one request, one answer; animated cards are pure UI) |

## AI

- `GET /api/ai/status` — Whether drafts are written by AI or, without an API key, by the sample generator.

## Assessments

- `DELETE /api/assessments/{id}` — Deletes a draft and its items; a published assessment is archived instead.
- `DELETE /api/assessments/{id}/items/{itemId}` — Removes an item from a draft; the following items move up.
- `DELETE /api/assessments/{id}/shares/{organizationId}` — Stops sharing the assessment in an organization; copies its members made stay theirs.
- `GET /api/assessments` — Lists the current user's assessments (and, with scope, those shared with them), optionally filtered by status.
- `GET /api/assessments/{id}` — Gets an assessment with its items in order, as the instructor sees it.
- `GET /api/assessments/{id}/items/{itemId}` — Gets one item, as the instructor sees it.
- `GET /api/assessments/{id}/preview` — The assessment as students will see it, without answer keys, notes or hints. Nothing is saved.
- `POST /api/assessments` — Creates a draft assessment, optionally with its items (an AI draft saved in one call).
- `POST /api/assessments/{id}/archive` — Archives a draft or published assessment.
- `POST /api/assessments/{id}/duplicate` — Creates a new draft with copies of the items, from any state.
- `POST /api/assessments/{id}/items` — Adds an item at the end of a draft.
- `POST /api/assessments/{id}/publish` — Publishes a draft with at least one item; it can no longer be edited.
- `POST /api/assessments/generate` — Proposes an assessment draft with AI from a topic and optional materials. Nothing is saved.
- `PUT /api/assessments/{id}` — Changes the title and instructions of a draft.
- `PUT /api/assessments/{id}/items/{itemId}` — Replaces an item of a draft (its type can change).
- `PUT /api/assessments/{id}/items/order` — Puts the items of a draft in a new order; the body lists every item id exactly once.
- `PUT /api/assessments/{id}/shares/{organizationId}` — Shares a published assessment in an organization the owner belongs to; its members can read and duplicate it.

## Assignments

- `DELETE /api/assignments/{id}` — Deletes an assignment without submissions.
- `GET /api/assignments` — Lists the current user's assignments (and, with scope, those of workspaces shared with them), optionally by workspace, assessment and availability.
- `GET /api/assignments/{id}` — Gets one of the current user's assignments, or one of a workspace shared with them, with its configuration.
- `POST /api/assignments` — Assigns a published assessment to an active workspace and creates its share token.
- `POST /api/assignments/{id}/close` — Closes the assignment now.
- `POST /api/assignments/{id}/reopen` — Reopens a closed assignment, optionally with a new due date in the future.
- `POST /api/assignments/{id}/share-token` — Replaces the share token; the previous link stops working.
- `PUT /api/assignments/{id}` — Replaces the window, the time limit and the Metis settings.
- `PUT /api/assignments/{id}/results-visibility` — Chooses whether students see their result after submitting; allowed in any state.

## Auth

- `GET /api/auth/me` — Gets the authenticated user.
- `POST /api/auth/sync` — With a Cognito ID token: creates the signed-in user (and their personal organization) in Metis on the first call and returns them on every call.

## Join

- `GET /api/public/join/{joinCode}` — Gets the workspace and teacher names for a join code (404 if unknown or archived).
- `POST /api/public/join` — Adds the student to the roster. Idempotent: an email already on the roster also succeeds.

## Metis

- `GET /api/assignments/{id}/conversations` — The conversations of the students with Metis in an assignment, one per student and item.
- `POST /api/assignments/{id}/doubts` — Groups what the students asked Metis into at most 6 frequent doubts, with a teaching suggestion each. Nothing is saved.

## Organizations

- `DELETE /api/organizations/{id}` — Deletes an organization with its memberships and invitations (owner; not the personal one).
- `DELETE /api/organizations/{id}/invitations/{invitationId}` — Revokes a pending invitation; its link stops working (owner or admin).
- `DELETE /api/organizations/{id}/members/{userId}` — Removes a member: the owner removes admins and teachers, an admin removes teachers.
- `GET /api/invitations/{token}` — Gets the organization and email of an invitation, and whether it can still be accepted.
- `GET /api/organizations` — Lists the current user's organizations with their role, the personal one first.
- `GET /api/organizations/{id}` — Gets one of the current user's organizations with its members.
- `GET /api/organizations/{id}/invitations` — Lists the pending invitations, newest first (owner or admin).
- `GET /api/organizations/{id}/join-code` — Gets the join code and whether it is enabled (owner or admin).
- `POST /api/invitations/{token}/accept` — Accepts the invitation as the signed-in user, who joins as a teacher.
- `POST /api/organizations` — Creates an organization owned by the current user, with its join code disabled.
- `POST /api/organizations/{id}/invitations` — Invites an email as a teacher and returns the link's token, only this once (owner or admin).
- `POST /api/organizations/{id}/join-code` — Replaces the join code; the previous one stops working (owner or admin).
- `POST /api/organizations/{id}/leave` — Leaves an organization (admins and teachers; the owner transfers ownership first).
- `POST /api/organizations/{id}/transfer` — Makes another member the owner; the current owner becomes an admin (owner).
- `POST /api/organizations/join` — Joins an organization as a teacher with its join code. Idempotent; a disabled code is a 404.
- `PUT /api/organizations/{id}` — Renames an organization (owner or admin).
- `PUT /api/organizations/{id}/join-code` — Enables or disables the join code (owner or admin; never enabled on the personal one).
- `PUT /api/organizations/{id}/members/{userId}/role` — Makes a member an admin or a teacher (owner).

## Public assignments

- `GET /api/public/assignments/{shareToken}` — What the student link shows: assessment, workspace, teacher, item count, window and availability (404 if unknown).

## Public submissions

- `GET /api/public/submissions/{accessKey}` — The submission as its student sees it: items without answer keys, saved responses, deadline and server time.
- `GET /api/public/submissions/{accessKey}/messages` — The student's conversations with Metis in this submission, in order, so the page can show them again.
- `GET /api/public/submissions/{accessKey}/result` — The student's result if the instructor made results visible; otherwise only that it was received.
- `POST /api/public/assignments/{shareToken}/start` — Starts the student's submission with their email (on the roster) and returns its access key; never returns the key of an existing one.
- `POST /api/public/submissions/{accessKey}/messages` — Sends the student's message about one item to Metis and returns Metis's reply, which never gives the answer.
- `POST /api/public/submissions/{accessKey}/submit` — Submits the submission and grades its objective items; submitting again only returns the status.
- `PUT /api/public/submissions/{accessKey}/responses` — Saves or removes the responses of several items (autosave).

## Results

- `GET /api/assignments/{id}/results` — The results of an assignment: averages, score distribution and per item achievement, answers, pending reviews and Metis helps.
- `GET /api/home` — The instructor's home: reviews pending by assignment, open assignments and recent drafts, in one light response.

## Sample data

- `DELETE /api/sample-data` — Deletes all of the current user's sample data, and only it.
- `GET /api/sample-data` — Whether the current user has sample data, with the open sample assignment and its demo emails.
- `POST /api/sample-data` — Loads a sample workspace, two published assessments and two assignments, one closed and graded, one open.

## Submissions

- `GET /api/assignments/{id}/submissions` — The whole roster of the assignment's workspace with the state of each student's submission.
- `GET /api/submissions/{id}` — A submission with every item, its answer key, the student's response and the result.
- `POST /api/submissions/{id}/allow-resume` — Lets the next start with the student's email continue this submission on another device (once).
- `PUT /api/submissions/{id}/items/{itemId}/review` — Scores an item (a pending essay, or an override of a graded item) with optional feedback.

## Workspaces

- `DELETE /api/workspaces/{id}` — Deletes a workspace and its roster; a workspace with assignments is archived instead.
- `DELETE /api/workspaces/{id}/shares/{organizationId}` — Stops sharing the workspace in an organization; its members stop seeing it at once.
- `DELETE /api/workspaces/{id}/students/{studentId}` — Removes a student without submissions from the roster.
- `GET /api/workspaces` — Lists the current user's workspaces (and, with scope, those shared with them), optionally filtered by status.
- `GET /api/workspaces/{id}` — Gets one of the current user's workspaces, or one shared with them.
- `GET /api/workspaces/{id}/students` — Lists the roster of a workspace.
- `GET /api/workspaces/{id}/students/{studentId}` — Gets one student of the roster.
- `POST /api/workspaces` — Creates a workspace with a new join code.
- `POST /api/workspaces/{id}/archive` — Archives a workspace: it stops accepting students and joins.
- `POST /api/workspaces/{id}/join-code` — Replaces the join code; the previous one stops working.
- `POST /api/workspaces/{id}/restore` — Restores an archived workspace.
- `POST /api/workspaces/{id}/students` — Adds a student to the roster.
- `POST /api/workspaces/{id}/students/bulk` — Adds up to 100 students at once (all or nothing); emails already on the roster are reported.
- `PUT /api/workspaces/{id}` — Renames a workspace.
- `PUT /api/workspaces/{id}/shares/{organizationId}` — Shares a workspace in an organization the owner belongs to. It exposes student data: names, emails and submissions.
- `PUT /api/workspaces/{id}/students/{studentId}` — Updates a student's name and email.
